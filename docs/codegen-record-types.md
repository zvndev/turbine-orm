# Generated entities named Record

A table named `records` generates the public entity `Record` and the accessor
`records`. These names also work with empty create inputs, nested connected-row
selectors and generated session-context declarations.

When an entity or enum declares `Record`, the generator emits its own string
dictionaries as inline mapped types. For example, the empty-input dictionary is
`{ [key in string]: never }`. This keeps the builtin utility's structural meaning
and `keyof` behavior without introducing another generated helper name.

Ordinary schemas retain their previous generated bytes. Explicit `columnTypes`,
code-first TypeScript declarations, enum labels and metadata retain their existing
meaning. Caller-written type expressions are emitted verbatim; this correction
does not reinterpret a caller's own use of `Record`. Other utility-name collisions
remain separate concerns.

The regression suite is
[the source generation test](../src/test/codegen-record.test.ts). It covers
all four generator targets, empty inputs, entity and enum names, overrides,
metadata preservation and deterministic emission.

[The installed-consumer fixture](../tooling/codegen-record-proof.mjs)
accepts public `generate` and `introspectSqliteDatabase` functions from an installed
package, a fresh consumer directory, and `format: 'esm' | 'cjs'`. The consumer must
have TypeScript and Node typings installed. Run it from that consumer directory
with Node 22.16 or Node 24.10, importing the package through the format being
checked. It retains generated sources, exact commands, unmarked negative
diagnostics and a native SQLite database for inspection.

The fixture checks default-only and nested empty creates, required child fields,
typed relation reads, scalar precision, large integers, nullable values, bytes,
rollback, committed writes and handle ownership. It queries native stored values
independently. PostgreSQL, MySQL and SQL Server generation checks establish emitted
type behavior; they do not establish native execution on those engines.
